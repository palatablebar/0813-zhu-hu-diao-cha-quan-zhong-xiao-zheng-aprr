# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 wave, census。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `stratum`、`households`、`responded`、`target` 排列。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

同一抽样层按批次合计入样和回应户数。精确有理数计算无应答调整，保留分子分母；分层总体与普查框核验。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
