# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 有迁户更正时选择 `迁户更正样例`。在业务阶段逐层核对迁户前后的户数、回应户数和权重；原层 `wave` 应答记录保留在台账，供追责。
5. 对账无差异、逐层权重等于最新普查目标且无坏行时可签发。仍有迁户冲突、缺目标层或重复挪户时会列出记录键并挡住签发。
6. 签发被挡不影响已存批次：旧版本、调整依据与失败尝试都保留，可填写暂缓意见或修正来源后重跑。
7. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。
